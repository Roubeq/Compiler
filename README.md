# Compiler

Учебный **компилятор для мини-языка** программирования, написанный на C++. Курсовая работа по дисциплине «Теория компиляции» (НГТУ им. Р. Е. Алексеева).

## О проекте
Проект реализует начальные этапы компиляции для небольшого императивного языка Pascal-подобного вида. Основа — **лексический анализатор (Lexer)**, который разбивает исходный текст на поток токенов.

### Поддерживаемые токены
`IDENTIFIER`, `KEYWORD`, `NUMBER`, `OPERATOR`, `ASSIGN`, `COMMENT`, `PARENTHESIS`, `SEPARATOR`, `STRING`, `END_OF_FILE`.

### Ключевые слова языка
`dim`, `integer`, `real`, `boolean`, `if`, `then`, `else`, `for`, `to`, `do`, `while`, `read`, `write`, `true`, `false`, оператор `not`, присваивание `ass`.

## Стек
- **C++** (`<fstream>`, `<unordered_map>`, `<vector>`)
- Собрано в Visual Studio (`.sln` / `.vcxproj`)

## Как запустить
```bash
g++ -std=c++17 <файл>.cpp -o compiler && ./compiler
```
или открыть решение `.sln` в Visual Studio и запустить.
